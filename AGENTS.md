# AGENTS.md

Static HTML/CSS/JS coursework site for 王垚's 《高级网页设计》. There is no root `package.json`, build, test, lint, or CI. Each page is standalone and opened directly in a browser.

## Before you edit

- Append every user prompt to `cf_prompt.md` (row: time | model | prompt) before acting. The rule is standing; keep the file untracked.
- Prefix new CSS class names, ids, and JS variables with `cf_`. Existing pages such as `grid.html` and `html_basic001.html` do not follow this; do not refactor them unless asked.
- Keep files UTF-8; content is Chinese.
- When adding a page, add a card/link to root `index.html` (the course catalog). The catalog is behind newer pages (`0609cf.html`, `iconfont-1..4.html`, etc.), so update it when adding/finishing pages.
- Use local assets only. Vendor third-party libraries under `cdn/` (Font Awesome: `cdn/font-awesome/all.min.css`; Lucide: `cdn/lucide/lucide.min.js`) and icons under `font/` (`iconfont.css`, `iconfont.js`). Do not add remote CDN URLs.

## Layout

- Root `*.html` + sibling `*.css` are individual practice pages; many keep CSS/JS inline. `index.html` is the catalog and entry point.
- `data.js` exposes global `window.STUDENTS` / `window.SUBJECTS`, consumed by `0609cf.html` (student-grade dashboard). Its comments mention `starter.html` / `target.html`; those files do not exist.
- `wangyao-information/` is a separate standalone mini-site with its own `img/` and relative links.
- `font/` and `cdn/` are vendored/generated assets. `font/iconfont.*` is generated by iconfont.cn; do not hand-edit.
- `git-portable/`, `git-portable.exe`, `.trae/`, and `cf_prompt.md` are local-only tooling/logs. They still show as untracked because the custom `.gitignore` entries have inline comments, which Git does not parse; never stage them.
- `.opencode/node_modules` is only the OpenCode plugin SDK. There is no root npm project; do not run npm build/test scripts.

## Verify

No automated checks exist. Open the changed page (e.g. `Start-Process .\index.html`) and confirm relative asset paths and responsive layout. There is no dev server.

- Active remote: `origin` → `https://gitee.com/chen-fu11/chen-fu.git`, branch `master`. Ignore stale `.opencode`/`.trae` skills that reference `neusoft_wangyao_jsj` or a separate `gitee` remote.
- The worktree already has unrelated deletions/modifications from earlier merges. Never use `git add -A` or `git add .`; stage only files you changed. Do not restore unrelated deleted student folders.
